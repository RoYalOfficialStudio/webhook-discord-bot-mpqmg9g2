The bot is untouched and still typechecks. A snapshot of it is in `SNAPSHOTS/0000_pre_roy_studio_initial/`.

## GMB 01 – Audio Foundation: PASS (headless)
Done: tempo map (tempo/time-signature changes), transport (play/pause/stop/seek/loop/count-in/pre-roll),
sample-accurate metronome, realtime render graph (routing, busses, pre/post sends, solo-in-place,
mute, phase, width, pan law, gain smoothing, meters), plugin delay compensation, automation,
atomic graph hot-swap with deferred deletion, NaN/Inf guard, offline render on the same code path,
miniaudio device manager (WASAPI/DirectSound on Windows; null backend used in tests).
Tested: 44.1/48/96 kHz × 32…1024 buffers give identical output; **0 heap allocations in the audio callback**.
Limitation: tested on the null backend only; no real audio hardware in this environment (UNTESTED on a real device).

## GMB 02 – Project Engine: PASS
Versioned JSON format (`.roy`), migration with backup, forward-compatible unknown keys, refusal to overwrite
files from newer versions, sessions with lock file, autosave to `RECOVERY/`, crash detection,
RECOVER PROJECT / OPEN LAST STABLE / DISCARD RECOVERY (moved aside, never deleted), numbered backups
with retention, milestones, undo/redo (mementos), command registry + macros + palette search + shortcuts.
Bug found by tests and fixed: a normal close could rotate away a crash snapshot that belonged to the user.
